第一章错题 · 四个漏洞 专项练习

共 6 题 · 每题对应一个漏洞
做之前先在心里说一遍「这题是哪个漏洞」，再动笔

练习 1漏洞① 逆定理

已知 △ABC 的三边分别为 a、b、c，请判断它是不是直角三角形。如果是，指出哪个角是直角：

  1. a = 8，b = 15，c = 17
  2. a = 5，b = 6，c = 8
  3. a = 1，b = √3，c = 2
  4. a = 3m，b = 4m，c = 5m（m > 0）
点开对答案

(1) 是，∠C = 90°。8² + 15² = 64 + 225 = 289 = 17²，c 最长，所以直角在 c 对着的角上，即 ∠C。

(2) 不是。5² + 6² = 25 + 36 = 61 ≠ 64 = 8²。

(3) 是，∠C = 90°。1² + (√3)² = 1 + 3 = 4 = 2²。

(4) 是，∠C = 90°。(3m)² + (4m)² = 9m² + 16m² = 25m² = (5m)²。

答题提醒：必须点明「哪个角是直角」——直角在最长边对着的那个角上。

练习 2漏洞① 逆定理（综合）

在 △ABC 中，AB = 13，AC = 15，BC = 14，AD 是 BC 边上的高，求 AD 的长。

小提醒：先设未知数把两条直角边表示出来，再用「同一个高」列方程。

点开对答案

答案：AD = 12

过程：设 BD = x，则 CD = 14 − x。

在 Rt△ABD 中：AD² = AB² − BD² = 13² − x²

在 Rt△ACD 中：AD² = AC² − CD² = 15² − (14 − x)²

两式相等：169 − x² = 225 − (196 − 28x + x²)

169 − x² = 29 + 28x − x²，解得 x = 5

∴ AD² = 169 − 25 = 144，AD = 12。

另一种更快的做法（先判直角）：13² + 14² = 169 + 196 = 365 ≠ 225，所以这不是直角三角形——所以只能老实用设未知数 + 勾股列方程。

练习 3漏洞② 立体展开

一个长方体纸箱，长 30 cm、宽 20 cm、高 10 cm。一只蚂蚁要沿着纸箱的外表面，从顶点 A 爬到与它正对面的顶点 B（体对角线的两个端点）。

(1) 求蚂蚁爬行的最短路径长度。

(2) 写出你这道题的关键方法。

点开对答案

(1) 答案：30√2 ≈ 42.4 cm

关键方法：把纸箱摊平成平面图，A、B 两点之间连直线，然后在【所有的摊平方式】里取最小。

把长方体摊平后，两条直角边分别由「两条棱长之和」和「第三条棱长」构成，共有三种摊法：

  • 水平 (30+20) = 50，竖直 10 → √(50² + 10²) = √2600 ≈ 51.0
  • 水平 (30+10) = 40，竖直 20 → √(40² + 20²) = √2000 ≈ 44.7
  • 水平 (20+10) = 30，竖直 30 → √(30² + 30²) = √1800 = 30√2 ≈ 42.4

三种走法比较后，最小的是 30√2 ≈ 42.4 cm。

(2) 三句话：① 沿棱剪开摊平 ② 两点之间线段最短 ③ 把所有摊法都比一遍，取最小。

易错点：只算一种摊法就下结论。这题三种摊法的结果差很多（51 / 44.7 / 42.4），必须全部算完再比。

练习 4漏洞② 复杂图形

在正方形网格中，已知两点 A、D 满足 AD² = 20（例如横向 2 格、纵向 4 格的斜线）。

现在再找一个格点 B′，使得 AB′² = 10 且 B′D² = 10。

(1) 判断 △AB′D 是什么三角形，说明理由（用逆定理）。

(2) 求 ∠B′AD 的度数。

(3) 如果 ∠BAC = ∠B′AC（即 B′ 是 B 关于 AC 的对称点），那么 ∠BAC + ∠DAC 等于多少度？

点开对答案

(1) △AB′D 是等腰直角三角形。

理由：∵ AB′² = 10，B′D² = 10，AD² = 20

∴ AB′ = B′D（等腰），且 AB′² + B′D² = 10 + 10 = 20 = AD²

由勾股定理逆定理，△AB′D 是直角三角形，直角对着最长边 AD，即 ∠AB′D = 90°。

有一个角是 90° 的等腰三角形是等腰直角三角形。

(2) ∠B′AD = 45°（等腰直角三角形的两个锐角都是 45°）

(3) ∠BAC + ∠DAC = 45°

∵ ∠BAC = ∠B′AC（对称），∴ ∠BAC + ∠DAC = ∠B′AC + ∠DAC = ∠B′AD = 45°。

方法总结：网格里的角，永远想两件事——① 用格点造直角三角形、算三边平方 ② 用对称/全等把目标角搬到一起。

练习 5漏洞③ 规律题

正方形 A₁B₁C₁D₁ 的边长为 1，面积记作 S₁。以它的一条边为斜边向外作等腰直角三角形，再以该三角形的直角边为边作正方形，面积记作 S₂；按此规律继续，依次得到 S₃、S₄、…

(1) 分别算出 S₁、S₂、S₃、S₄；

(2) 写出 Sₙ 的表达式；

(3) 求 S₈ 的值。

点开对答案

(1) S₁ = 1² = 1；S₂ = ½；S₃ = ¼；S₄ = ⅛

(2) Sₙ = (½)n−1

(3) S₈ = (½)8−1 = (½)7 = 1/128

为什么每次 ×½：「以边为斜边作等腰直角三角形」把边长变成原来的 1/√2（因为 斜边² = 2×直角边²），而面积是边长的平方，所以面积变成原来的 ½。

规律题三步法：① 代数字 ② 找关系 ③ 写通项。永远从「先算前三项」开始，不要盯着字母发呆。

练习 6漏洞④ 综合题

在 △ABC 中，∠C = 90°，AC = 6，BC = 8。

(1) 写出「用尺规作 ∠BAC 的平分线」的三个步骤（不用画图，写文字）。

(2) 设这条角平分线交 BC 于点 P，求线段 PC 的长。

(3) 如果题目改成「作 BC 的垂直平分线交 BC 于 P」，PC 又是多少？

点开对答案

(1) ① 以顶点 A 为圆心、任意长为半径画弧，分别交 AB、AC 于点 M、N；

② 分别以 M、N 为圆心、大于 ½MN 的同样长为半径画弧，两弧交于点 D；

③ 作射线 AD，则 AD 平分 ∠BAC。

(2) PC = 3

先算 AB = √(6² + 8²) = 10。

过 P 作 PD ⊥ AB 于 D。由角平分线的性质：PD = PC。

在 Rt△ACP 与 Rt△ADP 中，AP = AP、PC = PD → △ACP ≌ △ADP（HL）→ AD = AC = 6。

∴ BD = AB − AD = 10 − 6 = 4。

设 PC = PD = x，则 BP = BC − PC = 8 − x。

在 Rt△BDP 中：BP² = BD² + PD²，即 (8 − x)² = 4² + x²

64 − 16x + x² = 16 + x²，解得 x = 3，即 PC = 3。

(3) PC = 4

中垂线上的点到线段两端点距离相等 → PB = PC。设 PC = x，则 PB = x，而 PB + PC = BC = 8，所以 2x = 8，x = 4。

这道题的价值：同一个三角形、同样交在 BC 上，「角平分线」和「垂直平分线」是两条完全不同的线，答案也完全不同（3 vs 4）。所以第一步永远是先把作图痕迹翻译清楚。
