1. 练习 1 · 旋转法（换数字）

等腰直角 △ABC 中，∠ACB = 90°，AC = BC，P 在斜边 AB 上。以 PC 为直角边作等腰直角 △PCQ（∠PCQ = 90°），连接 BQ。已知 PB = 6，BQ = 8，求 PC 的长。（提示：先证 ∠PBQ = 90°，再两次勾股）

做完点这里对答案
∠PBQ = 45° + 45° = 90° → PB² + BQ² = PQ² → PQ² = 36 + 64 = 100。
△PCQ 等腰直角 → PQ² = 2PC² → PC² = 50 → PC = 5√2。

2. 练习 2 · 勾股分割点判定

点 M、N 把线段 AB 分成 AM = 3，MN = 5，NB = 4。M、N 是线段 AB 的勾股分割点吗？请说明理由。

做完点这里对答案
3² + 4² = 9 + 16 = 25 = 5²，以 3、4、5 为边的三角形是直角三角形（斜边 MN）。
是勾股分割点。

3. 练习 3 · 勾股分割点双解

M、N 是线段 AB 的勾股分割点，AM 为直角边，AB = 12，AM = 3，求 BN 的长。（提醒：斜边不确定，分几类？每个解都要检验！）

做完点这里对答案
MN + NB = 12 − 3 = 9。设 MN = x，NB = y。
情形① 斜边 MN：x² − y² = 9 → 9(x − y) = 9 → x − y = 1 → x = 5，y = 4 → BN = 4；
情形② 斜边 NB：y² − x² = 9 → y − x = 1 → y = 5，x = 4 → BN = 5。
答：BN = 4 或 5。（都是 3-4-5！）
