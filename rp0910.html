📝 0910 练习卷 · 旋转法

4 道题都是今天两道大题的换数字版。写在纸上、写全步骤（尤其是每个直角的出处），做完再点开答案核对。做完拍照发给老师。

1. 练习 1 · 第12(1) 换数字

等边 △ABC 内一点 O，OA=5，OB=12，OC=13。将 △BAO 绕点 B 顺时针旋转到 △BCD 处，连接 OD。
求：①旋转角的度数；②线段 OD 的长；③∠BDC 的度数。

做完点这里对答案
① 旋转角 = ∠ABC = 60°；
② BO=BD=12，∠OBD=60° → △BOD 等边 → OD=12；
③ CD=OA=5，OD=12，OC=13：5²+12²=169=13² → ∠ODC=90°；∠BDC=∠BDO+∠ODC=60°+90°=150°。

2. 练习 2 · 第13(1) 换数字

等边 △ABC 内有一点 P，P 到 A、B、C 的距离分别为 6、8、10。仿照阅读材料（将 △ABP 绕 A 旋转到 △ACP′），求 ∠APB 的度数。写出完整推理链。

做完点这里对答案
△APP′：AP=AP′=6，∠PAP′=60° → 等边 → PP′=6，∠AP′P=60°。
△PP′C：PP′=6，P′C=PB=8，PC=10 → 6²+8²=10² → ∠PP′C=90°。
∠APB = ∠AP′C = 60°+90° = 150°。

3. 练习 3 · 第13(2) 应用

等腰直角 △ABC 中 ∠CAB=90°，AB=AC，E、F 为 BC 上的点，∠EAF=45°。若 BE=3，FC=4，求 EF 的长。（提示：先用旋转构造，再用勾股）

做完点这里对答案
旋转 △ABE 绕 A 逆时针 90° → △ACE′：CE′=BE=3，AE′=AE，∠FAE′=∠EAF=45° → △AEF≌△AE′F → EF=E′F。
∠E′CF = 45°+45° = 90° → Rt△E′CF 中 E′F² = CE′² + FC² = 9 + 16 = 25。
EF = 5。

4. 练习 4 · 第13(3) 变式（能力提升）

Rt△ABC 中，∠ACB=90°，AC=2，∠ABC=30°，O 为内一点，∠AOC=∠COB=∠BOA=120°，求 (OA+OB+OC)² 的值。（把主课里的每一步都换成新数字重走一遍）

做完点这里对答案
旋转 △AOC 绕 C 逆时针 60°：OO′=OC，A′O′=AO，四点 A′、O′、O、B 共线 → OA+OB+OC = A′B。
△A′CB：CA′=2，CB=2√3，∠A′CB=150° → 作高：∠A′CH=30° → A′H=1，CH=√3，HB=√3+2√3=3√3。
A′B² = 1 + 27 = 28。答：28。
