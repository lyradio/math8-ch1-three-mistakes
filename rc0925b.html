🔥 第3题 (2025春·新都区期中) —— 旋转 + 三线合一

第 2/26 步读题 + 把条件全部摆上桌

已知：∠BAD = ∠CAE = 90°，AB = AD，AE = AC，AF⊥CB 于 F。要证：CD = 2BF + DE。

🧠 苏格拉底第一问：∠BAD = ∠CAE = 90°，这两个 90° 叠在一起，你能拆出哪对相等的角？
∠BAC = 90° − ∠CAD = ∠DAE
再加 AB = AD、AC = AE
→ △ABC ≌ △ADE（SAS）——这就是你会做的 (1)。

第 3/26 步(2) 复盘：∠FAE 为什么是 135°？

🧠 先盯着 △ACE 看：AC = AE 且 ∠CAE = 90°，它是什么三角形？

等腰直角三角形！所以 ∠ACE = ∠AEC = 45°。

由 (1) 全等 → ∠ACB = ∠AED
而 D 在 CE 上 → ∠AED 就是 ∠AEC = 45° → ∠ACB = 45°
AF⊥CB → 在 Rt△ACF 中：∠FAC = 90° − ∠ACB = 45°
→ ∠FAE = ∠FAC + ∠CAE = 45° + 90° = 135°
📌 这一问的钥匙：△ACE 是等腰直角三角形——这个 45° 后面 (3) 还要用到，记住它！

第 4/26 步(3) CD = 2BF + DE：为什么没思路？

🧠 苏格拉底第二问：要证 CD = 2BF + DE。看看图——BF 在左上角，DE 在右下角，CD 在右上角。
图里有哪个现成的三角形能同时装下这些线段吗？

没有。这就是你卡住的原因：全等三角形不存在，需要你造一个。

⚠️ 再想一层：题目给的「AB = AD + ∠BAD = 90°」是什么结构？
—— 两条相等的邻边，夹角 90°。这是「旋转」最典型的信号弹！
📌 旋转的野心：把 △ABF 绕 A 转 90°，AB 会落到 AD 上——那 BF 就被「搬」到了 D 那边去，和 DE 做邻居。

第 5/26 步构造：把 △ABF 绕 A 顺时针转 90°

想象 BF 这条线段跟着 △ABF 一起转：B → D（因为 AB=AD 且 ∠BAD=90°），F 转到一个新位置 F′。

旋转保长保角：
AF′ = AF，∠F′AD = ∠FAB，∠AF′D = ∠AFB = 90°
🧠 关键观察：∠AF′D = 90° 意味着 AF′⊥DF′。再看 (2) 里那个等腰直角 △ACE——从 A 向 CE 作垂线，垂足在哪？

垂足正好是 CE 的中点（等腰三角形三线合一）！而 F′ 满足 AF′⊥CE 且 AF′=AF 恰好落在 CE 上——所以 F′ 就在 CE 上，和 D、E 做了邻居。

第 6/26 步证明 △ABF ≌ △ADF′，拿到 BF = DF′

在 △ABF 和 △ADF′ 中：
AB = AD（已知）
∠BAF = ∠DAF′（旋转 / 等角加减）
AF = AF′（旋转保长）
→ △ABF ≌ △ADF′（SAS）→ BF = DF′
📌 考试写法不需要说「旋转」两个字，直接写：延长/在 CE 上取点 F′，使 ∠DAF′ = ∠BAF，连 DF′——然后 SAS。旋转只是你想的方式，写出来是「作一个角」。

第 7/26 步收尾：三线合一 + 拼线段

等腰 Rt△ACE 中 AF′⊥CE 于 F′
→ 三线合一 → CF′ = F′E

图上顺序是 C — F′ — D — E：
CF′ = F′D + DE
CD = CF′ + F′D = (F′D + DE) + F′D = 2F′D + DE
又 F′D = BF
→ CD = 2BF + DE ✅
✅ 回顾整个思路：散落的 BF 和 DE → 旋转把 BF「搬」到 D 旁边变成 DF′ → 等腰直角三角形三线合一给出 CF′=F′E → 沿 CE 一条线拼完。全程只用你已会的：SAS + 三线合一。

第 8/26 步反应测试：下次见到什么就转？

A. 只要有直角就旋转
B. 两条邻边相等 + 夹角 90°（或互补），绕公共顶点旋转
C. 线段分散时随便连一条辅助线试试
D. 等腰三角形一律旋转
🔥 第4题 (2018春·金牛区期中) —— 半角模型三部曲

第 9/26 步读题 (1)：½∠BAD 是信号弹

四边形 ABCD 中，AB = AD，∠B = ∠D = 90°，E、F 分别在 BC、CD 上，∠EAF = ½∠BAD。求证 EF = BE + DF。

🧠 苏格拉底第一问：结论是「EF = BE + DF」——三条线段一条在左、一条在右、一条斜着横跨。谁和谁能拼到一起？

BE 和 DF 分散在两个角上。而 AB = AD、∠B = ∠D = 90°——又是「相等的邻边 + 相等的夹角」！旋转信号弹再次升起。

📌 母套路名字：半角模型。只要见到 ∠EAF = ½∠BAD（一半角），标准动作就是把 △ADF 旋转到 △ABF′ 的位置，把 DF 搬到 BE 旁边拼起来。

第 10/26 步构造：△ADF 绕 A 转，AD 落到 AB 上

把 △ADF 绕 A 旋转，AD 与 AB 重合，F → F′
则 AF′ = AF，BF′ = DF，∠ABF′ = ∠ADF = 90°
🧠 F′ 落在哪？∠ABF′ = 90° = ∠ABC，而 ∠ABF′ 和 ∠ABC 共顶点 B、共边 AB——两个 90° 拼在一起说明 BF′ 和 BC 是同一条直线！

所以 F′ 在 CB 的延长线上，BF′ 和 BE 手拉手站成一条线：BF′ = BE + EF′。

第 11/26 步关键一步：∠F′AE = ∠FAE

∠F′AE = ∠F′AB + ∠BAE = ∠FAD + ∠BAE

而 ∠FAD + ∠BAE = ∠BAD − ∠EAF = ∠BAD − ½∠BAD = ½∠BAD = ∠EAF

→ ∠F′AE = ∠FAE ✅
📌 这就是「半角」的作用：½∠BAD 恰好等于剩下的两边角之和。旋转把 ∠FAD 搬到 ∠F′AB 后，两个小角正好拼回一个 ∠EAF。这是半角模型的核心拼角。

第 12/26 步SAS 全等，收网

在 △AEF′ 和 △AEF 中：
AF′ = AF（旋转保长）
∠F′AE = ∠FAE（上一步拼出来的）
AE = AE（公共边）
→ △AEF′ ≌ △AEF（SAS）→ EF′ = EF

而 EF′ = EB + BF′ = EB + DF
→ EF = BE + DF ✅
✅ 完整链条：旋转搬线段 → 90° 保证共线 → 半角拼出等角 → SAS 全等 → 拼线段收尾。和第3题如出一辙！

第 13/26 步反应测试：这个证明里，90° 立了什么功？

A. 90° 让三角形变大了
B. 90° 用来证等腰三角形
C. ∠ABF′=∠ABC=90°，保证 F′ 落在 CB 延长线上，BE 和 BF′ 才能拼成一条线段
D. 90° 只是巧合，没有实际作用

第 14/26 步(2) ∠B + ∠D = 180°：结论还成立吗？

🧠 苏格拉底第二问：∠D 不再是 90°，旋转后 ∠ABF′ = ∠D 也不再是 90° 了。那 F′ 还在 CB 延长线上吗？
∠ABF′ + ∠ABC = ∠D + ∠B = 180°
→ ∠ABF′ 与 ∠ABC 互补，且共顶点 B、共边 AB
→ BF′ 与 BC 成一条直线 → F′ 仍在 CB 延长线上！

后面三步（拼半角 → SAS → EF = EF′ = BE + BF′ = BE + DF）一模一样。结论仍然成立。

📌 (1) 的 90° 只是特例；本质要求是 ∠B + ∠D = 180°（对角互补）——这就是「对角互补模型」。旋转 + 互补 = 共线。

第 15/26 步(3) E、F 跑到延长线上：和会变成差

同样的旋转：△ADF ≌ △ABF′，F′ 仍在 CB 延长线上
同样的拼角：∠F′AE = ∠FAE → △AEF′ ≌ △AEF → EF = EF′

但现在 E 在 BC 延长线上、跑到了 F′ 的外面：
EF′ = BE − BF′ = BE − DF
→ EF = BE − DF（和变成了差）
⚠️ 为什么变了：之前 E 在 F′ 内侧，EF′ = EB + BF′；现在 E 跑到外侧，EF′ = BE − BF′。辅助线和全等一步没变，变的只是点的位置关系。这就是这类题第 (3) 问的考点——不换方法，换位置。

第 16/26 步反应测试：半角模型的完整信号是？

A. 只要看到 45° 就旋转
B. 共顶点两邻边相等 + 对角互补 + 一个「一半角」∠EAF=½∠BAD → 旋转 △ADF 到 △ABF′
C. 证 EF=BE+DF 只能截长补短，不能旋转
D. 需要用相似三角形才能证
🔥 第5题 (2016春·锦江区同步) —— 构造迁移：第(1)问是第(2)问的钥匙

第 17/26 步读题 (1)：题目让你「先造再证」

∠ABC = 90°，D 在直线 AB 上（B 在 A、D 之间），AD = BC。(1) 过 A 作 AF⊥AB，截取 AF = BD，判断 △CDF 的形状。

🧠 苏格拉底第一问：这次题目直接把构造告诉了你（AF⊥AB、AF=BD）。看看 △FAD 和 △DBC——它们能用哪条判定？
AF = BD（作图）
∠FAD = ∠DBC = 90°（AF⊥AB，CB⊥AB）
AD = BC（已知）
→ △FAD ≌ △DBC（SAS）

第 18/26 步导角：∠FDC = 90° 是怎么「平移」出来的？

全等 → FD = DC 且 ∠FDA = ∠DCB

D 在直线 AB 上（平角 180°）：
∠FDC = 180° − ∠FDA − ∠BDC
= 180° − ∠DCB − ∠BDC
= ∠DBC = 90°（△BCD 内角和）

FD = DC 且 ∠FDC = 90° → △CDF 是等腰直角三角形 ✅

📌 全等导角的经典手法：把相等的角「换」到平角上来算。∠FDA 换成 ∠DCB，剩下的角就等于 ∠DBC=90°。这个「等角代换 + 平角」组合要熟。

第 19/26 步(2) 关键转折：你会做完 (1) 就翻篇吗？

(2) 说：E 在直线 BC 上，CE = BD，直线 AE、CD 交于 P，∠APD 是定值吗？

🧠 苏格拉底第二问（最重要的一问）：CE = BD，而 (1) 里你亲手作的 AF 也 = BD。那 AF 和 CE 是什么关系？

AF = CE！而且 AF⊥AB、CB⊥AB → AF∥BC，即 AF ∥ CE。

⚠️ 这就是你丢分的真正原因：不是 (2) 太难，是做完 (1) 没回头问一句——「我这个构造，(2) 还能用吗？」。压轴题的 (2) 几乎总是踩着 (1) 的肩膀。

第 20/26 步AF∥CE 且 AF=CE → 平行四边形

AF ∥ CE 且 AF = CE
→ 四边形 AFCE 是平行四边形（一组对边平行且相等）
→ AE ∥ FC
🧠 看到 AE∥FC 想到什么？直线 AE 和 FC 平行，CD 是截线——P 处的 ∠APD 和 C 处的 ∠FCD 是什么关系？

同位角！∠APD = ∠FCD。

第 21/26 步定值揭晓：∠APD = 45°

由 (1)：△CDF 是等腰直角三角形 → ∠FCD = 45°
AE∥FC → ∠APD = ∠FCD（同位角）
→ ∠APD = 45°，是定值 ✅
✅ 完整链条：(1) 的构造 AF=BD → 恰好 = CE → 平行四边形 → 平行 → 同位角 → (1) 的 45° 直接搬过来。第 (2) 问一步新全等都没证，全靠「迁移」。

第 23/26 步复盘：你卡住的不是一个题，是一个动作

⚠️ 三个卡点，一个根源：
