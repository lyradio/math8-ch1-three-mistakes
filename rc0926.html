第 2/32 步诊断小测：这道题你会不会

先别看题，回答一个最基础的问题——它就是今天全部内容的地基：

√(a²) 等于什么？
A. a
B. |a|（a 的绝对值）
C. ±a
D. a²
⚠️ 记住这条：√(a²) = |a|，不是 a。a 是正数时等于 a，a 是负数时等于 −a。
今天三道题的每一个坑，都是从这一条长出来的。
🔥 第6题 · 大根号套分式（隐藏的取值范围）

第 3/32 步读题：先把题面看清

计算：√[(a²−4a+4)/(a²−4a+3)] · √(3−a)/(a−2) + √(1−a)
🧠 苏格拉底第一问：看到这一串，你的手是不是马上想开始「分解因式、约分」？
先停一下。在动笔之前，有一步必须做在前面——否则后面每一步都可能符号错。
📌 这一步是：先把 a 的取值范围定下来（题目没给，但它藏在每个根号和每个分母里）。

第 4/32 步第一步永远是找「隐藏条件」

逐个点名式子里每一个根号和每一个分母：

① √(1−a) 有意义 → 1−a ≥ 0 → a ≤ 1
② √(3−a) 有意义 → 3−a ≥ 0 → a ≤ 3（已被①包含）
③ 分母 a²−4a+3 = (a−1)(a−3) ≠ 0 → a ≠ 1 且 a ≠ 3
④ 分母 a−2 ≠ 0 → a ≠ 2

把①和③合起来：a ≤ 1 且 a ≠ 1 → a < 1。

现在测一下你找全没有：

A. a ≤ 1
B. a < 1
C. a ≤ 3
D. a < 2
⚠️ A 是最大的陷阱：漏掉「分母 ≠ 0」就只能得到 a ≤ 1。但 a=1 时 a²−4a+3 = 0，整个式子没有意义，必须挖掉。答案 a < 1。

第 5/32 步拆因式：两个二次式都要拆

a² − 4a + 4 = (a−2)²
a² − 4a + 3 = (a−1)(a−3)
⚠️ 易错点一：因为 a < 1，所以 a−1 < 0、a−3 < 0，两个都是负数。
根号里不能留负数，所以要改写成两个正数相乘：
(a−1)(a−3) = [−(1−a)]·[−(3−a)] = (1−a)(3−a)
于是 √(a²−4a+3) = √[(1−a)(3−a)] = √(1−a) · √(3−a)。
📌 口诀：二次根式里碰到两个负因式，先各自提个负号变成正，再拆根号。

第 6/32 步关键一跳：√((a−2)²) 到底等于什么

第一项的分子是 √(a²−4a+4) = √((a−2)²)。按开场那条 √(a²)=|a|：

A. a − 2
B. 2 − a
C. |a−2|，再由 a < 1 得 2 − a
D. 条件不够，判断不了
√((a−2)²) = |a−2|
因为 a < 1 < 2，所以 a−2 < 0 → |a−2| = 2 − a
⚠️ 这道题 90% 的错误出在这里：直接写 √((a−2)²) = a−2。
如果没有前面「a < 1」这个范围，你根本没法去绝对值——这就是为什么第一步必须先定范围。

第 7/32 步第一项化简完成

第一项 = √(a²−4a+4) / √(a²−4a+3)
= (2−a) / [√(1−a) · √(3−a)]

分子是 2−a（正数），分母是两个正根号相乘。第一项搞定，放一边。

📌 先别急着跟第二项相乘。盯住第二项看一眼——它身上有一个看不见的负号。

第 8/32 步第二项的隐藏负号：分母是负的！

第二项 = √(3−a) / (a−2)
⚠️ 易错点二：a < 1，所以 a−2 < 0 —— 分母是负数！
很多人直接把它当正数去约分，结果整道题的符号就反了。
正确写法：√(3−a)/(a−2) = − √(3−a)/(2−a)
🧠 苏格拉底第二问：为什么这里不能写成 √[(3−a)/(a−2)]？
因为 a < 1 时 (3−a) > 0、(a−2) < 0，比值是负数，根号里没有意义。所以根号只罩住 3−a，不罩分母。

第 9/32 步相乘：根号全部消掉，只剩一个负号

第一项 × 第二项
= (2−a) / [√(1−a)·√(3−a)] × [ − √(3−a)/(2−a) ]
= − (2−a)·√(3−a) / [ (2−a)·√(1−a)·√(3−a) ]
= − 1/√(1−a)

(2−a) 约掉，√(3−a) 约掉，只剩分母的 √(1−a) 和那个负号。

✅ 一堆根号，两刀就砍没了。剩下的活只有一步：加上最后的 √(1−a)。

第 10/32 步加上最后一项，得到结果

原式 = −1/√(1−a) + √(1−a)
= [ −1 + (1−a) ] / √(1−a)
= −a / √(1−a)
= −a√(1−a) / (1−a)（分母有理化）
✅ 第6题答案：−a√(1−a)/(1−a)，也就是 −a/√(1−a)。
📌 通分这一步最容易错：把 √(1−a) 看成 √(1−a)/1，通分时分子要乘 (1−a) 而不是 1。

第 11/32 步验算：随便挑两个数代进去对一对

取 a = 0（满足 a < 1）代入原式：

√(4/3) · √3/(−2) + √1 = (2/√3)·(−√3/2) + 1 = −1 + 1 = 0
公式：−a/√(1−a) = 0/1 = 0 ✓

再取 a = −3：

√(25/24) · √6/(−5) + √4 = [5/(2√6)]·(−√6/5) + 2 = −1/2 + 2 = 3/2
公式：−a/√(1−a) = 3/√4 = 3/2 ✓
✅ 两个数都对上，说明符号没搞反。

第 12/32 步反应测试：下次一眼该看出什么

已知 x < 3，下面哪个等式一定成立？

A. √(x²−6x+9) = x − 3
B. √(x²−6x+9) = 3 − x
C. √(x²−6x+9) = ±(x−3)
D. 没法判断
📌 信号弹：看到根号里是完全平方（如 (x−3)²），立刻做两件事——
① 写成 |x−3|；② 用题目（或隐含条件）给的 x 范围把绝对值去掉。
🔥 第7题 · ab=7 求值（根号外的字母怎么搬进去）

第 13/32 步读题

已知 ab = 7，求 a√(b/a) + b√(a/b) 的值。
🧠 苏格拉底第一问：这题看起来比第6题简单得多——但为什么它反而是错得最多的一道？
因为它有一个看起来天经地义、其实是错的动作。

第 14/32 步大多数人的第一反应（错在哪）

常见写法：a√(b/a) = √(a²)·√(b/a) = √(a²·b/a) = √(ab) = √7
同理 b√(a/b) = √7，所以答案 = 2√7
A. 完全正确
B. 错在 a 可能是负数，√(a²)=|a| 不是 a
C. 错在 b/a 可能是负数
D. 错在 ab=7 推不出 √(ab)=√7
⚠️ 坑就在这里：把外面的 a 搬进根号，a 要先变成 √(a²)，而 √(a²)=|a|，不是 a。
如果 a 是负数，搬进去之后前面要多一个负号。

第 15/32 步正确写法：搬进根号前先看符号

若 a > 0：a√(b/a) = √(a²)·√(b/a) = √(a²·b/a) = √(ab) = √7
若 a < 0：a√(b/a) = −|a|·√(b/a) = −√(a²·b/a) = −√(ab) = −√7

同理，b√(a/b) 这一项的正负由 b 的符号决定。

📌 一句话：外面那个字母是正，搬进去不变号；是负，搬进去要在根号前补一个负号。

第 16/32 步关键：ab=7 到底告诉了我们什么

ab = 7 > 0，说明 a 和 b 同号。但——是同正，还是同负？

A. a > 0 且 b > 0
B. a、b 同号（同正或同负）
C. a、b 异号
D. 什么都推不出来
⚠️ 这就是这题的题眼：ab=7 只保证同号，不保证都是正数。
所以必须分两种情况讨论。

第 17/32 步情况一：a、b 都是正数

a > 0 → a√(b/a) = +√7
b > 0 → b√(a/b) = +√7
原式 = √7 + √7 = 2√7

代入一组数检验：a=1，b=7 → 1·√7 + 7·√(1/7) = √7 + √7 = 2√7 ✓

第 18/32 步情况二：a、b 都是负数

a < 0 → a√(b/a) = −√7
b < 0 → b√(a/b) = −√7
原式 = −√7 − √7 = −2√7

代入一组数检验：a=−1，b=−7 → (−1)·√7 + (−7)·√(1/7) = −√7 − √7 = −2√7 ✓

📌 注意 b/a = (−7)/(−1) = 7 > 0，根号照样有意义，所以这种情况是合法的，不能丢。

第 19/32 步考场怎么写才能拿满分

✅ 完整答案：±2√7（a、b 同正取 +2√7，同负取 −2√7）
标准写法三步：
① 由 ab=7>0 得 a、b 同号；
② 当 a>0、b>0 时，原式 = 2√7；
③ 当 a<0、b<0 时，原式 = −2√7。
∴ 原式的值为 ±2√7。
📌 如果练习册的答案只印了 2√7，那是它默认了 a、b 是正数。你在卷子上把两种情况都写全，两种答案标准都不会算你错。

第 20/32 步反应测试：换个数你还会在吗

已知 ab = 5，且没有其他条件，则 a√(b/a) + b√(a/b) 的值是？

A. 2√5
B. −2√5
C. ±2√5
D. 条件不足，求不出
📌 信号弹：只要题目给出的是 ab = 正数（只给乘积、不给单个字母的正负），就要自觉分类讨论。
🔥 第8题 · 整体代入（不求出 x 也能算）

第 21/32 步读题

已知 √x + 1/√x = 2，求 √(x²+3x+1) − √(x²+4x+1) 的值。
🧠 苏格拉底第一问：题目给的是 √x + 1/√x，要求的是 √(x²+3x+1)。
这两个式子长得完全不像，它们之间唯一的桥是什么？

第 22/32 步看到 x²+3x+1，第一反应应该是什么

A. 先解方程把 x 求出来，再代入
B. 从根号里提一个 x 出来，凑成 x·(x + 3 + 1/x)
C. 把 x²+3x+1 配方
D. 两边平方把根号去掉
📌 为什么选 B：题目给你的是「x 和 1/x 捆在一起」的条件，那你就把要求的式子也凑成 x 和 1/x 的样子——这叫整体代入。
（A 也能做对，但那是「笨办法」；B 是压轴题真正要考的思维。这一课两条路都走一遍。）

第 23/32 步提一个 x 出来：根号里立刻现形

x² + 3x + 1 = x·(x + 3 + 1/x)
∴ √(x²+3x+1) = √[ x·(x + 3 + 1/x) ] = √x · √(x + 1/x + 3)
同理 √(x²+4x+1) = √x · √(x + 1/x + 4)
⚠️ 能这样拆的前提：x > 0（有 √x 就说明 x>0），而且 x + 1/x + 3 > 0。两个都满足，放心拆。
📌 手法名字：分子分母同除以 x（这里是「根号里同提出 x」）——凡见到 x²+ax+1 这种首尾对称的式子，就把它提出来。

第 24/32 步把已知条件也变成 x + 1/x

已知：√x + 1/√x = 2
两边平方：(√x)² + 2·√x·(1/√x) + (1/√x)² = 4
即：x + 2 + 1/x = 4
∴ x + 1/x = 2
📌 中间那一项 2·√x·(1/√x) = 2，是完全平方公式的固定产物，永远消得掉 x。这就是「√x + 1/√x」和「x + 1/x」之间的固定通道。

第 25/32 步代入：两个根号瞬间变干净

√(x²+3x+1) = √x · √(2 + 3) = √x · √5
√(x²+4x+1) = √x · √(2 + 4) = √x · √6
∴ 原式 = √x·√5 − √x·√6 = √x · (√5 − √6)
🧠 苏格拉底第二问：还差最后一个未知量 √x。题目只给了 √x + 1/√x = 2，能把 √x 单独揪出来吗？

第 26/32 步揪出 √x：用「平方差」这一招

A. √x = 1
B. √x = 2
C. √x = √2
D. 求不出来
(√x − 1/√x)² = (√x + 1/√x)² − 4·√x·(1/√x) = 4 − 4 = 0
∴ √x − 1/√x = 0 → √x = 1/√x → x = 1 → √x = 1
📌 也可以设 t = √x > 0：t + 1/t = 2 → t² − 2t + 1 = 0 → (t−1)² = 0 → t = 1。

第 27/32 步结果 + 用笨办法验一遍

✅ 原式 = 1 × (√5 − √6) = √5 − √6

笨办法验算（先求 x 再代入）：由上面得 x = 1，直接代原式：

√(1² + 3·1 + 1) − √(1² + 4·1 + 1) = √5 − √6 ✓
📌 两条路得到同一个答案。考场上用哪条？——如果题目给的已知条件比较复杂（比如 √x + 1/√x = 3），解 x 会很麻烦，那时候整体代入就是唯一能走通的路。所以这一招必须练熟。

第 28/32 步反应测试：换个数试试整体代入

已知 √x + 1/√x = 3，则 x + 1/x 等于多少？

A. 3
B. 7
C. 9
D. 11
(√x + 1/√x)² = x + 2 + 1/x = 9 → x + 1/x = 7
🏆 总结 · 三个坑，一条母套路

第 29/32 步错因复盘：你掉的其实是同一个坑

⚠️ 坑一：不先找取值范围（第6题）
没先定出 a < 1，后面 √((a−2)²) 到底去不去绝对值、分母是正还是负，全都判断不了。
⚠️ 坑二：根号内外搬家忘了符号（第6、7题）
√(a²) = |a| 不是 a。搬出来的要加绝对值，搬进去的要先看正负。
⚠️ 坑三：只会「先求 x 再代入」（第8题）
题目给的是整体（x + 1/x），就不会把要求的式子也凑成整体。
📌 三个坑其实是一个：动手太快，定性太慢。

第 30/32 步母套路：三步法，通吃这三道题

✅ 第一步 · 定范围
把所有隐含条件列出来：被开方数 ≥ 0、分母 ≠ 0。写在草稿纸最上面。
✅ 第二步 · 定符号
凡是出现 √(A²)，先写 |A|，再用第一步的范围去掉绝对值；
凡是要把根号外的字母搬进根号，先判断它的正负。
✅ 第三步 · 整体代入
已知给的是「x + 1/x」这类整体，就把要求的式子也凑成这个整体（提 x / 除以 x），别急着解方程。
📌 这三步的顺序不能颠倒：先定范围 → 再定符号 → 最后才动手算。

第 31/32 步防错三问：写完每道题，问自己三句

① 我有没有先写取值范围？
② 我搬进／搬出根号的时候，有没有想到 √(a²)=|a| 并看符号？
③ 我能不能不求出字母的值，直接整体代入？

三句都答得上来，这道题就不会再错了。
