🔥 母套路① 非负性之和为零（选择4 + 填空15）

第 1/23 步读题（选择4）：这个等式有什么奇怪的地方？

原题：若 √(a−1) + (b+2)² + |c| = 0，求 a、b、c 的值。

🧠 苏格拉底第一问：一个等式右边是 0，左边却加了三项。三项加起来等于 0，每项可能是什么数？
A. 三项都可能取到负数
B. 三项每一项都不可能是负数
C. 只有两项不可能是负数
D. 无法确定符号

第 2/23 步非负性"三板斧"——本章最重要的一张牌

初二数学里只有三样东西永远不是负数：

① |x| ≥ 0（绝对值）
② √x ≥ 0（算术平方根，且要求 x ≥ 0）
③ x² ≥ 0（完全平方）
⚠️ 核心推论（考试 directly 考这个）：
几个非负项之和 = 0 ⟺ 每一项都 = 0。
为什么？只要有一项 > 0，和就 > 0 了，凑不出 0。所以必须是"全部归零"。
📌 条件反射训练：以后看到「根号 + 平方 + 绝对值 加起来 = 0」这个组合，脑子里要立刻弹出三个小等式。这就是母套路①。

第 3/23 步用母套路①秒杀选择4

√(a−1) = 0 → a − 1 = 0 → a = 1
(b+2)² = 0 → b + 2 = 0 → b = −2
|c| = 0 → c = 0

所以 a=1, b=−2, c=0，对照选项选 D（正确答案）。

⚠️ 你当时为什么错：很可能只让其中一两项为零，或者把 (b+2)²=0 解成 b=2（忘了移项变号）。母套路没建立条件反射，三个小等式少写一个就错。

第 4/23 步同款套路：填空15

原题：已知实数 a,b 满足 ½|a−b| + √(2b+c) + c²−4c+4 = 0，求 a²+b²+c² 的算术平方根。

🧠 先自己想一想：这次三项里有一项不是"标准三板斧"形态——c²−4c+4。它是什么？

第一步：把 c²−4c+4 认出来——这是完全平方公式！

c² − 4c + 4 = (c−2)²

于是等式变成：½|a−b| + √(2b+c) + (c−2)² = 0

第二步：母套路①，三项全归零：

(c−2)² = 0 → c = 2
√(2b+c) = 0 → 2b + 2 = 0 → b = −1
½|a−b| = 0 → a = b = −1

第三步：算目标：

a² + b² + c² = 1 + 1 + 4 = 6
6 的算术平方根 = √6 ✓

（题目问法以你的练习册原文为准；核心就是母套路① + 认出完全平方）

🔥 母套路①进阶：配方法造非负项（填空16 · 压轴）

第 5/23 步读题（填空16）：这次等式里藏着什么？

原题：已知 a+b+c+5 = 2(√(a−1) + √(b+1) + √(c+2))，求 a²+b²+c² 的值。

🧠 苏格拉底第一问：这次没有"…= 0"，三项也不是直接加在一起。母套路①还能用吗？

提示：能不能把所有东西移到一边，凑出"几个非负项之和 = 0"？
A. 不能，因为没有 = 0 的条件
B. 能，把右边的 2√(a−1) 拆成两个 √(a−1)，一个移到左边去配方
C. 能，两边同时平方就行
D. 这题条件不够，做不出来

第 6/23 步配方全过程（核心技巧，必须看懂每一步）

关键动作：把 2√(a−1) 拆成 √(a−1) + √(a−1)，一个留在右边、一个移到左边：

(a − 1) − 2√(a−1) + (b+1) − 2√(b+1) + (c+2) − 2√(c+2) + (1+1+1) + ……

等等，常数怎么配平？慢慢来，一项一项看。对 a 这一组：

a − 2√(a−1) − 1 = (a−1) − 2√(a−1) + 1 − 2 = (√(a−1) − 1)² − 2

三组都这么拆，常数 5 = (−1)+(−1)+(−1) + 2 + 2 + … 直接用凑的形式写最终结果：

a+b+c+5 = 2√(a−1) + 2√(b+1) + 2√(c+2)
⟺ (√(a−1) − 1)² + (√(b+1) − 1)² + (√(c+2) − 1)² = 0
📌 为什么可以这样拆：展开右边验证——
(√(a−1)−1)² = (a−1) − 2√(a−1) + 1 = a − 2√(a−1)，三个加起来正好是 a+b+c − 2√(a−1) − 2√(b+1) − 2√(c+2)。
移项回来 = 原等式。✓

第 7/23 步三项归零，填空16 完成收尾

√(a−1) − 1 = 0 → a = 2
√(b+1) − 1 = 0 → b = 0
√(c+2) − 1 = 0 → c = −1
a² + b² + c² = 4 + 0 + 1 = 5 ✓（与答案一致）
🏆 母套路①完整版总结：
① 初级：√x + |y| + z² = 0 → 三项直接归零（选择4、填空15）
② 进阶：字母 + 常数 = 2√(字母∓常数) → 先配方再造非负项，再归零（填空16）
配方暗号：看到「a − 2√(a−1)」这种形态，条件反射写 (√(a−1) − 1)²。
🔥 母套路② √(a²) = |a|（选择7 + 22(4) 的地基）

第 8/23 步√(a²) 到底等不等于 a？做个实验

🧠 苏格拉底实验：拿 a = −3 代进去试试。
√(a²) = √((−3)²) = √9 = ? 是 3 还是 −3？
A. 是 −3，因为 √(a²) = a
B. 是 3，因为算术平方根必须是正数或零
C. 无意义，负数不能开平方
D. 取决于 a 的正负

第 9/23 步结论：√(a²) = |a|，什么时候才等于 a？

√(a²) = |a|（永远成立）

什么时候 √(a²) = a？ → 只有 a ≥ 0 时
什么时候 √(a²) = −a？ → 当 a < 0 时（|a| = −a）
⚠️ 你选错的原因（B 选项 √(a²)=a）：脑子里默认了"a 是正数"。题目说的是"一定成立"——a 取负数就翻车。这是本章第一大陷阱！
📌 防错口诀：「开方先想负，结果加绝对」。没告诉你 a≥0，就老老实实写 |a|。

第 10/23 步选择7 收尾 + 一个重要扩展

正确答案：D（√(a²) = |a|）。

顺手扩展——同样道理的兄弟公式（22(4) 会用到）：

√(a²b) = |a|·√b（b ≥ 0 时）
√(a/b) = √(ab) / |b|（ab ≥ 0, b ≠ 0 时）← 分母要加绝对值！
🔥 母套路②实战：22(4) 字母开方的符号处理

第 11/23 步读题（22(4)）：先判断 x、y 的符号

原题：已知 x + y = 8，xy = 8，求 y√(y/x) + x√(x/y) 的值。

🧠 苏格拉底第一问：开方之前，必须先搞清楚 x、y 是正是负（不然就会踩 √(a²)=|a| 的坑）。
xy = 8 > 0 说明什么？x + y = 8 > 0 又说明什么？
A. x、y 一正一负
B. x、y 一正一零
C. x、y 同号，且都是正数
D. 符号无法判断

第 12/23 步关键化简：把 √(y/x) 变成"分母带绝对值"的形式

技巧：把 y/x 的分子分母同乘 x，凑出 xy：

√(y/x) = √(y·x / x·x) = √(xy) / √(x²) = √(xy) / |x|

x、y 都是正数 → |x| = x，所以：

y√(y/x) = y·√(xy)/x
x√(x/y) = x·√(xy)/y（同理）

原式 = √(xy)·(y/x + x/y) = √(xy)·(x²+y²)/(xy)
⚠️ 如果题目给的是 x+y=−8（两负）：|x| = −x，整个式子多一个负号，答案变 −12√2。符号判断决定答案正负——这就是 22(4) 的命门。

第 13/23 步代入求值，22(4) 完成收尾

需要两个零件：

零件① x² + y² = (x+y)² − 2xy = 64 − 16 = 48
零件② √(xy) = √8 = 2√2
原式 = √(xy)·(x²+y²)/(xy) = (x²+y²)/√(xy) = 48 / (2√2) = 24/√2 = 12√2 ✓
🏆 这题的完整母套路链：
① xy>0 且 x+y>0 → 都是正数（符号判断）
② √(y/x) = √(xy)/|x|（化统一）
③ x²+y² = (x+y)²−2xy（对称式拆解）
④ 分母有理化收尾
你错的原因：大概率是符号没判断，或 √(y/x) 直接写成了 √y/√x（y 是字母，没保证正，不能这么拆）。
🔥 母套路③ 概念辨析三板斧（选择6 + 选择8 + B卷2-1）

第 14/23 步选择6：无理数判定——一个反例就能毙掉一个选项

方法：判断"说法正确"的题，不要凭感觉，每个选项试着举一个反例：

A.「无理数都是有限小数」→ 反例：√2 = 1.41421356…（无限）→ ❌
B.「无限小数都是无理数」→ 反例：1/3 = 0.333…（无限但循环，是有理数）→ ❌
C.「带根号的数不都是无理数」→ 反例：√4 = 2（带根号但是有理数）→ ✓ 说法正确
D.「无理数与数轴上的点一一对应」→ 错，是「实数」与数轴上的点一一对应（数轴上还有有理数的点）→ ❌

正确答案：C。

⚠️ 你错的原因：无理数定义模糊 + 没有逐项举反例的习惯。记住：数轴 ↔ 实数（全体），不是无理数。

第 15/23 步选择8：最简二次根式只有两个"准入条件"

最简二次根式必须同时满足：
① 被开方数不含分母（分母里没有根号、被开方数不是分数）
② 被开方数不含能开得尽方的因数/因式

快速检验示范：

√2 → ✓ 最简
√(1/2) → ✗ 含分母（要化成 √2/2）
2√2 → ✓ 最简（系数 2 不影响"最简"，最简只看被开方数）
√18 → ✗ 18 = 9×2，9 能开尽方（化成 3√2）
√8 → ✗ 8 = 4×2（化成 2√2）

按你练习册里给的 5 个式子逐个套这两条，数出个数即可（题干以原书为准，答案 A：只有 1 个）。

第 16/23 步B卷2-1：估算夹逼——√2 到底在哪两个整数之间？

原题：m、n 是两个连续整数，且 m < −√2 < n，求 m + n。

🧠 三步走：
① 先算正的：1² = 1 < 2 < 4 = 2² → 1 < √2 < 2，更精确 √2 ≈ 1.414
② 加负号翻方向：−2 < −√2 < −1（注意不等号方向会翻转！）
③ 所以 m = −2，n = −1 → m + n = −3
⚠️ 你答 4 的原因：多半是忘了负号会让区间翻转（−√2 不是夹在 1 和 2 之间，是夹在 −2 和 −1 之间）。负数的估算，先正后负、方向翻转，八个子字记住。
🔥 母套路④ 找规律 + 新定义（21(1)(2) + B卷2-2/6）

第 17/23 步21(1)：观察规律——从具体数字里"嗅"出公式

观察这串等式（式子以你练习册为准，规律同型）：

√(4 + 4/15) = 4√(4/15)
√(5 + 5/24) = 5√(5/24)
√(6 + 6/35) = 6√(6/35)
🧠 苏格拉底观察任务：左边被开方数是「n + n/□」，右边是「n√(n/□)」。这个 □ 和 n 是什么关系？
15 = 4²−1，24 = 5²−1，35 = 6²−1 → □ = n²−1！

第 18/23 步21(2)：写出并用计算验证一般式

猜想：√(n + n/(n²−1)) = n√(n/(n²−1))（n ≥ 2 的整数）。

验证（找规律题必须验证，这是拿分步骤）：

右边平方 = n² · n/(n²−1) = n³/(n²−1)
左边平方 = n + n/(n²−1) = [n(n²−1) + n]/(n²−1) = (n³ − n + n)/(n²−1) = n³/(n²−1)
两边平方相等，且都是非负数 → 等式成立 ✓
📌 找规律题的通用三步：①列具体值找分母与 n 的关系 ②写一般式 ③平方验证。不验证会被扣过程分。

第 19/23 步B卷2-2：共轭根式——先算 a+b 和 ab，再拼对称式

题型特征：给 a = √3−√2, b = √3+√2 这种"一减一加"的共轭对，求 a²+b²（或 a³b+ab³ 等）。

万能两步：
① a + b = 2√3　　ab = (√3)² − (√2)² = 3 − 2 = 1
② a² + b² = (a+b)² − 2ab = 12 − 2 = 10
⚠️ 千万不要把 a、b 各自平方再相加——√3−√2 的平方会带 √6 交叉项，算又慢又容易错。对称式 = 先算和与积，这是代数式求值的通用铁律（22(4) 里的 x²+y² 也是这么拆的！）。

（你练习册里的具体数字可能不同，方法完全一样：先 a+b，再 ab，最后代对称式。）

第 20/23 步B卷2-6：新定义题 = 把定义翻译成方程

原题：规定：若一个非零实数的算术平方根等于它的立方根，则称这个数为"最美实数"。求最美实数的值。

翻译：设这个数为 a，"算术平方根 = 立方根" 即
√a = ∛a

设 x = √a = ∛a → 则 a = x² 且 a = x³
→ x² = x³ → x²(x − 1) = 0
→ x = 1（x=0 时 a=0，但要求非零，舍）
→ a = 1
📌 新定义题三板斧：①把定义逐字翻译成等式 ②解方程 ③检查定义里的附加条件（本题的"非零"就是用来舍根的！）。
