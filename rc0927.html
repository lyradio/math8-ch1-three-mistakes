🔥 第 15 题(2) · 根式混合运算

第 3/28 步读题：把式子看清

计算：√12 − (√3+1)² + 2/√3

这道题 8 分，错在最后一行。我们一步一步看：是哪一步的「纪律」出了问题。

第 4/28 步错因：把不能合并的项硬合并

⚠️ 看学生的第三行：
2√3 − 3 − 1 − 2√3 + 2√3/3
到这里其实只剩 −4 + 2√3/3，已经做完了。
但学生把 −4 也当成带 √3 的项，硬写成 −10√3/3。
📌 计算纪律一：合并同类项前，先问「它们是同类项吗？」常数和根式是两类，不能通分合并。

第 5/28 步正确写法：三步完成

Step 1 化简各项：
√12 = 2√3，(√3+1)² = 3 + 2√3 + 1 = 4 + 2√3，2/√3 = 2√3/3

Step 2 代入：
原式 = 2√3 − (4 + 2√3) + 2√3/3
= 2√3 − 4 − 2√3 + 2√3/3

Step 3 合并真正的同类项：
2√3 − 2√3 = 0，剩下 −4 + 2√3/3 = (2√3 − 12)/3

第 6/28 步互动：学生错在哪一步

学生过程：
原式 = 2√3 − (3+1+2√3) + 2√3/3
= 2√3 − 3 − 1 − 2√3 + 2√3/3
= −10√3/3

错误发生在第几行？

A. 第一行：展开 (√3+1)² 错了
B. 第二行：去括号符号错了
C. 第三行：把常数 −4 错误合并进根式项
D. 答案本来就应该写成 −10√3/3
🔥 第 16 题 · 整式乘法的符号

第 7/28 步读题：化简再求值

先化简，再求值：(2a+b)² − (2a+b)(2a−b) − 2b²
其中 a = √3 + 1，b = √3 − 1

这也是一道 8 分题，错在展开时的符号。符号错一步，后面全错。

第 8/28 步错因：平方差公式前面有个减号

⚠️ 学生第一行：(2a+b)² − 4a² − b² − 2b²
他把 (2a+b)(2a−b) 当成了 4a² + b²，前面再减，就变成 −4a² − b²。
正确应该是 (2a+b)(2a−b) = 4a² − b²，前面有负号，所以是 −4a² + b²。
📌 计算纪律二：去括号/去分数线前，先给整段套括号，再变号。

第 9/28 步正确化简：括号法

原式 = (2a+b)² − [(2a+b)(2a−b)] − 2b²
= (4a² + 4ab + b²) − (4a² − b²) − 2b²
= 4a² + 4ab + b² − 4a² + b² − 2b²
= 4ab

看到没？b² − (−b²) 这里是关键。给被减部分先加中括号，就不容易变号出错。

第 10/28 步代入求值：ab 是整体

a = √3 + 1，b = √3 − 1
ab = (√3+1)(√3−1) = 3 − 1 = 2
原式 = 4ab = 8
📌 计算纪律三：先化简到最简再代值。不要像学生那样带着 4ab − 2b² 往下算。

🔥 第 23 题 · 等腰三角形中的直角分类

第 12/28 步读题：把条件拆出来

在 △ABC 中，CA = CB，AB = 8，AC = 5。
D 在 AB 上动，E 与 A 关于直线 CD 对称。
当 △ADE 是直角三角形时，求 AD 的长。

注意关键词：对称、直角三角形、动点。这三个词一出现，就要警惕分类讨论。

第 13/28 步关键：对称的性质

E 与 A 关于 CD 对称 → CD 是 AE 的垂直平分线
→ 点 D 在 CD 上，所以 AD = ED
→ △ADE 是等腰三角形，两腰 AD = ED

既然 AD = ED，直角顶点不能是 A 或 E（两个底角相等，不可能同时为 90°），只能是 D。

📌 压轴小问纪律一：遇到「直角三角形」，立刻写「直角顶点可能是 A、D、E」。先枚举，再排除。

第 14/28 步建坐标：把几何变成代数

取 AB 中点 M。∵ CA = CB = 5，AB = 8，∴ AM = 4。
高 CM = √(5² − 4²) = 3。
建系：M(0,0)，A(−4,0)，B(4,0)，C(0,3)。
设 D 坐标为 (d,0)，则 AD = d + 4。

这一步是初二方法：遇到等腰三角形，常用「三线合一」作高，然后坐标化。

第 15/28 步列方程：∠ADE = 90° 怎么表达

CD 是 ∠ADE 的角平分线（对称轴），所以 ∠ADC = ∠EDC。
又 ∠ADE = 90°，所以 ∠ADC = 45° 或 135°。

用向量点积或斜率：
cos∠ADC = (DA·DC) / (|DA|·|DC|) = d / √(d²+9)

令 ∠ADC = 45° 或 135°，得到 d = 3 或 d = −3。

第 16/28 步两个答案：为什么容易漏

当 d = 3 时，D 靠近 B，AD = 7；
当 d = −3 时，D 靠近 A，AD = 1。
⚠️ 漏答案的根因：学生只画了一个位置的 D，没有想「D 在 AB 上左右移动时，图形会不会变化」。只要题目说「动点」，就要把边界和两侧都想到。

C. ∠ADE
D. 条件不足，无法判断
🔥 第 25 题(2) · 证明写到一半停了

第 18/28 步读题：这是一道几何证明的压轴小问

在 △ABC 中，∠ACB = 90°，AC = BC，CD 交 BD 于 E，连接 EO。
(2) 连接 CO 并延长交 ... 于点 F，求证：OE = OF。

从卷子看，学生写到 OC = OB = OA 就停了。问题是：这些只是准备，还没碰到结论 OE = OF。

第 19/28 步证明线段相等的「三板斧」

第一板斧：证全等 △___ ≌ △___ → 对应边相等。
第二板斧：找中点、中位线、直角三角形斜边中线 = 斜边一半。
第三板斧：等量代换，若 a = b 且 c = b，则 a = c。

第 25 题(2) 明显走第一板斧：去找包含 OE 和 OF 的两个三角形，证全等。

第 20/28 步如何把证明写完整：「目标倒推法」

目标：OE = OF
它俩在哪两个三角形里？△OEC 和 △OFA？还是 △OEB 和 △OFA？
已有的条件：OC = OA，∠COE = ∠AOF（对顶角），若能再找一组角/边相等，全等就成立。
📌 压轴小问纪律二：写证明前先写「我要证 ___，需要证 ___」。缺条件就在已知里找，找不到就作辅助线。

第 21/28 步学生错在哪：没有把「中间结论」变成「全等条件」

⚠️ 学生得出 OC = OB = OA，这是对的，但它只是「背景条件」。
下一步应该立刻写：
∵ OC = OA，∠COE = ∠AOF，再证 ∠OCE = ∠OAF（或 OE 与 OF 所在另一组角）
从而 △OCE ≌ △OAF，得到 OE = OF。

写到一半停，本质上是没有明确下一步目标。

🔥 第 26 题(3) · 旋转 + 点到直线距离

第 23/28 步读题：第 26 题(3) 也是最后一问

在 Rt△ABC 中，∠C = 90°，BC = 2AC = 6，∴ AC = 3。
(3) D 在射线 BC 上，将 AD 绕 A 顺时针转 90° 得 AF，连接 BF。
当 2CD = BD 时，直接写出 F 到直线 AB 的距离。

卷子上这一问是空白的。这说明不是不会做，而是没时间/没敢写。其实用坐标法很快。

第 24/28 步建坐标与旋转

建系：C(0,0)，A(0,3)，B(6,0)。
D 在射线 BC（x 轴）上，设 D(d,0)。
条件 2CD = BD：
2|d| = |6 − d| → d = 2 或 d = −6。
📌 压轴小问纪律三：看到「射线」二字，立刻分两种情况：点在射线上/延长线上。

第 25/28 步旋转 90°：向量法一步到位

向量 AD = (d, −3)。
顺时针旋转 90°：(x,y) → (y, −x)。
∴ 向量 AF = (−3, −d)。
F = A + AF = (−3, 3 − d)。

这就是初二能用的「坐标旋转」：把旋转变成向量旋转，避免画图找角度。

第 26/28 步点到直线距离：两个答案

直线 AB 的方程：x + 2y − 6 = 0。
F(−3, 3−d) 到 AB 的距离：
d_F = |−3 + 2(3−d) − 6| / √5 = |−3 − 2d| / √5。

当 d = 2 时：d_F = 7/√5 = 7√5/5；
当 d = −6 时：d_F = 9/√5 = 9√5/5。
✅ 完整答案：7√5/5 或 9√5/5。
📝 总结 · 从 124 到 145 的两套纪律

第 27/28 步计算题不出错的 3 条纪律

1. 先定取值范围/化简：根号、分母、绝对值先处理；
2. 去括号先套中括号：把被减/被除的整段括起来，再变号；
3. 合并同类项前叫停：常数、根式、字母项，先分类再合并。

这三条不是技巧，是纪律。考试时写在草稿纸顶端，每做一步对一下。

第 28/28 步压轴小问拿满分的「三步收尾法」

第一步：枚举
看到「直角」「等腰」「射线」「动点」，先列所有可能情况；

第二步：目标倒推
把结论写在最上面，问自己「证它需要什么条件？」缺什么补什么；

第三步：验算/复现
答案算出来后，花 10 秒代入原题条件检查一遍。
📌 这节课的 5 道题，错因全部可以归到「纪律没落地」或「收尾没写完」。先把这两个动作练成习惯，分数自然会上来。
