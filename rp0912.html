旋转作辅助线 · 配套练习卷

做之前先把「配对表」写出来，再动笔算

练习 1 · 概念判断（不定项）

把一个三角形绕某个点旋转 60° 之后，下面哪些说法一定成立？

  1. 旋转中心那个点的位置没有变化
  2. 所有的边长都保持不变
  3. 所有的内角大小都保持不变
  4. 旋转前后的两个三角形全等
点开对答案

答案：A、B、C、D 全选。

这四条正是旋转的性质，缺一不可：中心不动、边长不变、角度不变、前后全等（SAS）。

注意第 D 条不是「大概全等」，是严格全等——所以可以直接写 ≌ 并用它推边等、角等。

练习 2 · 配对训练（本题最关键）

已知：等边 △ABC，P 是内部一点。把 △ABP 绕点 A 逆时针旋转 60°，落到 △ACP′ 的位置。

请把下面的配对表补全：

  • AB → ______（等于谁）
  • AP → ______（等于谁）
  • BP → ______（被搬到哪儿去了）
  • ∠ABP → ______（对应角）
  • ∠APB → ______（对应角）
  • 写出全等式：△ABP ≌ ______，依据是 ______
  • 额外收获：连 PP′ 后，△APP′ 是什么三角形？为什么？
点开对答案

答案：

  • AB → AC（AB = AC，等边或用旋转：B 落到 C）
  • AP → AP′（AP = AP′，旋转性质）
  • BP → CP′（BP = CP′，这就是「搬走的那条边」）
  • ∠ABP → ∠ACP′
  • ∠APB → ∠AP′C
  • 全等式：△ABP ≌ △ACP′，依据 SAS（AB=AC，∠BAP=∠CAP′，AP=AP′）
  • △APP′ 是等边三角形：因为 AP = AP′（旋转），且 ∠PAP′ = 60°（就是旋转角）。 「有一个角是 60° 的等腰三角形是等边三角形」→ PP′ = AP。

这张表就是「不再找不到全等」的解药，务必背到能默出来。

练习 3 · 60° 定量实战

等边 △ABC，P 为内部一点，已知 PA = 5，PB = 12，PC = 13。

求 ∠APB 的度数。

小提醒：用「绕 A 逆时针转 60°」，先写配对表，再看白送的那个等边三角形。

点开对答案

答案：∠APB = 150°

过程：

  1. 把 △ABP 绕 A 逆时针旋转 60° → △ACP′，则 P′C = PB = 12，AP′ = AP = 5。
  2. 连 PP′：△APP′ 是等边三角形 → PP′ = 5，且 ∠AP′P = 60°。
  3. 看 △PP′C：三边是 PP′=5、P′C=12、PC=13。
    因为 5² + 12² = 25 + 144 = 169 = 13²，由勾股定理逆定理得 ∠PP′C = 90°。
  4. 于是 ∠AP′C = ∠AP′P + ∠PP′C = 60° + 90° = 150°。
  5. 由全等 ∠APB = ∠AP′C = 150°。

坑点：千万别直接写「因为 5²+12²=13²，所以 ∠APB=90°」——5、12、13 不在 ∠APB 这个三角形里， 必须先搬过去才能用。这一步是整套题的灵魂。

练习 4 · 90° 定量实战

正方形 ABCD，P 为内部一点，已知 PA = 1，PB = 2，PC = 3。

求 ∠APB 的度数。

小提醒：这次是 90° 卡片——绕顶点 B 转，白送的是等腰直角三角形。

点开对答案

答案：∠APB = 135°

过程：

  1. 把 △ABP 绕 B 旋转 90°，使 BA 落到 BC 上 → P 落到 P′，得 △CBP′ ≌ △ABP。
  2. 于是 BP′ = BP = 2，P′C = PA = 1，且 ∠PBP′ = 90°。
  3. △PBP′ 中：BP = BP′ = 2，夹角 90° → 等腰直角，得 PP′ = 2√2，∠BP′P = 45°。
  4. 看 △PP′C：PP′=2√2、P′C=1、PC=3。
    (2√2)² + 1² = 8 + 1 = 9 = 3² → ∠PP′C = 90°。
  5. ∠APB = ∠BP′C = ∠BP′P + ∠PP′C = 45° + 90° = 135°。

和练习 3 对比着看：60° 版本是「60° + 90° = 150°」，90° 版本是「45° + 90° = 135°」。 结构完全一样，只是折算出来的那个角度不同。

练习 5 · 方案设计（专治「不知道该转谁」）

不做计算，只要求你写出旋转方案。每一小题请把这四项都写全：

①绕哪个点　②转多少度　③把哪个三角形转到哪里　④转完白送什么

(1) 等边 △ABC，内部一点 P，已知 PA、PB、PC。目标：把 PB 搬走。

(2) 正方形 ABCD，内部一点 P，已知 PA、PB、PC。目标：把 PA 搬到 C 那边去。

(3) 等腰 △ABC，AB = AC，顶角 ∠A = 40°，内部一点 P。目标：把含 PB 的那块搬走。

点开对答案

(1) ①绕 A；②逆时针 60°；③把 △ABP 转到 △ACP′； ④白送 等边 △APP′（于是 PP′ = AP），且 BP = CP′。

(2) ①绕 B（因为要让 BA 落到 BC 上，BA=BC 是正方形的边）；②90°； ③把 △ABP 转到 △CBP′；④白送 等腰直角 △PBP′（于是 PP′ = √2·BP），且 AP = CP′。

(3) ①绕顶角顶点 A；②40°（顶角就是旋转角）； ③把 △ABP 转到 △ACP′；④白送一个腰长为 AP、顶角 40° 的等腰 △APP′，且 BP = CP′。

三小题的答案结构完全一样，只有「转多少度」和「白送什么三角形」不同。 记住这个模板，考场上遇到任何背景都能套。
